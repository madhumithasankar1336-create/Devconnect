# DevConnect – Developer Networking & Portfolio Platform

A LinkedIn-meets-GitHub style platform for developers.

## Features
- Email and GitHub OAuth login, password reset, HttpOnly cookie JWT auth
- Developer profiles with skills, education, experience and social links
- Project showcase with screenshots, repo and live demo links
- Technical blogs with likes and comments
- Developer search and skill-based recommendations
- Connection requests (send, accept, reject, remove)
- Skill endorsements (one per user per skill)
- Real-time notifications via Socket.io

## Tech Stack
React 18 · Vite · TypeScript · Tailwind CSS · TanStack Query · Zustand
Node.js · Express · Prisma · PostgreSQL · Socket.io · Cloudinary
Deploy: Vercel (client) · Railway (server) · Neon (database)
